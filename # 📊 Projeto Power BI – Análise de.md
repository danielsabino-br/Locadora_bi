**# 📊 Projeto Power BI – Análise de Dados de Locadora de Veículos**



**## 📌 Sobre o Projeto**



Este projeto está sendo desenvolvido com o objetivo de praticar e aprimorar habilidades em \*\*Power BI\*\* e \*\*análise de dados\*\*.



A proposta consiste na criação de um \*\*dashboard interativo\*\* utilizando dados de uma locadora de veículos, permitindo visualizar informações importantes como número de locações, clientes cadastrados, receita gerada e outros indicadores relevantes para a gestão do negócio.



Este trabalho está sendo realizado \*\*para fins acadêmicos e de aprendizado\*\*, com foco no desenvolvimento de competências em \*\*Business Intelligence (BI)\*\*.



---



**## 🎯 Objetivos do Projeto**



\* Praticar \*\*modelagem de dados\*\*

\* Utilizar \*\*Power Query\*\* para tratamento e transformação de dados

\* Criar \*\*medidas utilizando DAX\*\*

\* Construir \*\*dashboards interativos\*\*

\* Desenvolver habilidades em \*\*análise e visualização de dados\*\*



---



\## **🧰 Ferramentas Utilizadas**



\* Microsoft Power BI

\* Power Query

\* Linguagem DAX

\* Microsoft Excel (base de dados)



---



**## 📂 Estrutura do Projeto**



O projeto utiliza bases de dados contendo informações como:



\* Clientes

\* Locações de veículos

\* Informações de veículos

\* Dados de valores de locação



Esses dados são utilizados para gerar \*\*indicadores e visualizações analíticas\*\* no dashboard.



---



**## 📊 Indicadores que estão sendo desenvolvidos**



Alguns dos indicadores que serão apresentados no dashboard:



\* Total de clientes

\* Total de locações realizadas

\* Receita total

\* Veículos mais alugados

\* Locações por cidade

\* Evolução das locações ao longo do tempo
